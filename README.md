# argos


## objetivo
Esse é um repositório de um software livre para geração de pendrives de instalação de sistemas operacionais;

## requisitos
Software deve ser capaz de gerar pendrives tanto para windows quanto para distribuições linux, tanto para computadores com MBR/BIOS como computadores com GPT/UEFI;

Software deve ser confiável e rápido; Deve ser possível de instalar nas mais diversas distribuições linux; De forma ideal, inclusive no macos;

## inspiração
Uma boa inspiração é o Rufus - software livre disponível em https://github.com/pbatard/rufus; Entretanto, o Rufus é limitado a Windows;
