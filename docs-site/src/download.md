# Download

The links below go straight to the files on GitHub — no need to browse the repository or its Releases page to find them.

## Recommended per platform

- **macOS**: Homebrew (`brew install jp-guimaraes/argos/argos`) is the primary install path and the only one Gatekeeper never blocks. The `.dmg` below is the convenience download for anyone who wants the GUI without a Homebrew/Rust setup.
- **Debian / Ubuntu**: the `.deb` below (`sudo apt install ./argos_<version>_amd64.deb`).
- **Arch / pacman**: not published to the AUR yet — see [`packaging/README.md`](https://github.com/jp-guimaraes/argos/blob/main/packaging/README.md) for building the `PKGBUILD` locally.
- **Anything else**: the plain tarball for your platform below.

Every method's full instructions and caveats (Gatekeeper, Full Disk Access, `PATH` setup) are in [Overview](./overview.md), under Installation.
